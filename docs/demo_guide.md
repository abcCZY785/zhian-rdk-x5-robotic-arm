## Prerequisites

1. RDK X5 powered on and connected via USB-serial
2. Camera connected and accessible
3. ArUco markers placed on tabletop corners
4. YOLO model weights in `models/weights/`

## Running the Demo

```bash
# Start the vision module
make vision

# Run the full demo pipeline
make demo
```
